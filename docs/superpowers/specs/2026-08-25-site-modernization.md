# Site Modernization Specification

The site uses `https://plewandow.ski` as its canonical address.

The `www` name and the GitHub Pages name redirect to the canonical address.

The site keeps all posts, resources, and personal data.

The site uses the complete Minimal Mistakes 4.28.1 theme runtime.

The theme runtime includes all release templates, styles, data, and browser scripts.

Local overrides keep the Inter variable font, the wider layout, Mermaid 11.17.2, and MathJax 4.1.3.

The browser bundle uses jQuery 3.7.1 and Font Awesome 7.3.1.

The site supports current desktop and mobile browsers.

The build test verifies the canonical domain, release version, scripts, fonts, and removed obsolete services.

The final checks cover the build, browser console, diagrams, equations, DNS, HTTPS, and redirects.
